系统管理 ​

在左侧菜单进入系统管理。这里分两块：上面是上传策略，下面是存储一致性检查。

上传策略的修改保存后立即生效，无需重启服务。

单文件最大体积 ​

限制单个文件的大小，默认 500 MB，可设置 1 ~ 102400 MB。

超出限制的文件会在开始上传前就被拒绝，不会占用服务器空间。

允许上传的文件类型 ​

有两种模式：

  • 允许所有文件类型（默认）—— 不做任何限制。
  • 只允许指定类型 —— 填写允许的扩展名，例如 pdf,docx,xlsx,png,jpg。

填写时格式很宽松：可以用逗号、分号、空格或顿号分隔，大小写不限，前面的点可写可不写。例如下面这些写法效果相同：

pdf,docx,xlsx
.PDF .Docx .XLSX
pdf、docx、xlsx

页面提供了几个常用预设（仅文档与图片、仅图片、压缩包与文档），点一下即可填入。

留空 = 允许全部

把输入框清空，就恢复为允许所有类型。

文件保留天数 ​

文件上传后经过多少天自动删除（进入回收站），默认 15 天，可设置 1 ~ 3650 天。

修改后：

  • 新上传的文件按新天数计算到期时间。
  • 已上传的文件仍按原来的到期时间生效。

回收站保留天数 ​

文件进入回收站后继续保留多少天，默认 7 天，可设置 0 ~ 365 天。

  • 保留期内，管理员可以在文件与回收站中恢复文件。
  • 保留期结束后，文件会被彻底删除（磁盘文件与记录一并删除，不可恢复）。
  • 设为 0 表示进入回收站后立即彻底删除。

分片大小 ​

大文件分片上传时每片的大小，默认 4 MB，可设置 1 ~ 64 MB。

一般不需要调整。网络较差的场景可以调小，内网高速环境可以调大。

修改只影响新的上传任务，进行中的任务不受影响。

可预览上限 ​

限制能在线预览的文件大小，默认 20 MB，可设置 0 ~ 102400 MB。

预览要把整个文件读到浏览器里再解析，文件太大容易把页面卡住甚至卡死，所以单独设一道闸。

超出上限的文件：

  • 点预览会提示「超过在线预览上限，请下载后查看」，不会去加载内容；
  • 下载完全不受影响 —— 下载到本地照常打开。

设为 0 表示不限制

填 0 就是关掉这道闸，多大都能在线预览。内网带宽充足、机器性能好时可以这么设。

这只是预览的闸，不是上传的闸

「单文件最大体积」决定能不能传上来，这个决定能不能在线看。两个互不影响。

永久空间配额 ​

「设为永久」的文件永远不会被自动清理，所以给这类文件总量封一个上限，默认 100 GB，可设置 0 ~ 104857600 MB。

它是全站共享的一个池：系统里所有人设成永久的文件加起来不能超过这个数。不是每人一份 —— 否则总量会随人数无限增长，磁盘迟早被撑爆。

用户点「设为永久」时会看到二次确认，里面显示已用多少、还剩多少；超出时无法再设，并提示还差多少。

设为 0 = 关闭永久功能

填 0 就不提供「设为永久」这个入口，所有文件都按保留天数到期。

已设为永久的文件不会被回收

把配额调小（甚至调到低于当前已用量）时，已经设成永久的文件不受影响， 只是新的「设为永久」会因为超额而被拒绝。避免"改个配置就把用户的东西收走"。

允许上传 ​

总开关。关闭后所有用户都无法上传新文件，已上传的文件不受影响。

适合在维护、迁移或磁盘空间告急时临时关闭。

关于到期的完整流程 ​

两个天数共同决定了文件在服务器上最多保留多久。默认配置下最长约 22 天。

存储一致性检查 ​

用于确认数据库记录与磁盘文件是否一致，点击「扫描」执行。

扫描结果分三类：

类型含义处理方式
孤儿文件磁盘上有文件，但数据库里没有记录系统会自动归档到临时目录并保留 7 天后删除
缺失文件数据库有记录，但磁盘上的文件不见了说明文件被误删或磁盘故障，需要从备份恢复
非法路径数据库里出现了不合法的路径属于异常数据，建议联系开发者排查

什么时候用

  • 怀疑有文件丢失时
  • 手动操作过服务器上的文件或目录后
  • 定期巡检（例如每月一次）

三项都为 0 表示数据库与磁盘完全对应，这是正常状态。
