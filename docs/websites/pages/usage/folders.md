# 整理文件夹

文件多了以后，用文件夹把「我的文件」整理成一棵树，找起来快得多。

## 新建文件夹

进入**我的文件**，点右上角的**新建文件夹**，输入名字即可。

- 想建子文件夹，先**点进**某个文件夹，再点新建 —— 新文件夹会建在当前这一层里。
- 同一层里不能有同名文件夹，重名会提示你换一个。
- 文件夹名里的 `/ \ : * ? " < > |` 这些符号会被自动去掉（它们不是合法的文件名）。

## 进入和返回

点文件夹卡片就进入该文件夹，列表里只会显示这个文件夹里的文件。

列表上方的**面包屑**（比如 `我的文件 / 报表 / 2026`）会显示你当前的位置：

- 点**我的文件**回到最外层；
- 点中间任意一层，直接跳回那一层。

## 改名字、挪位置、删除

鼠标移到文件夹卡片上，右侧有三个按钮：

| 按钮 | 作用 |
| --- | --- |
| 分享 | 生成这个文件夹的分享链接（见[分享文件与文件夹](./share)） |
| 改名 | 改文件夹名字 |
| 删除 | 删除文件夹**以及里面的所有文件** |

::: warning 删除文件夹会连里面的文件一起删
删除后文件夹里的文件会进入**回收站**（和直接删文件一样），管理员还能恢复；
超过回收站保留天数才会被真正清理掉。

如果你只是想调整结构，用**改名**就够了；需要连文件一起挪走时再考虑删除后重建。
:::

## 上传到指定文件夹

**先点进那个文件夹**，再把文件拖进上传区 —— 文件就会传到当前所在的那一层，
不会堆在最外层。

上传进度、断点续传都和以前一样：网断了刷新页面，还没传完的会接着传。

::: tip 每个人有自己的文件夹树
文件夹是你自己的，别人看不到你的文件夹结构。「全部文件」里按人查看时，
看到的是那个人的文件夹树（别人的文件夹你只能浏览和下载，不能改）。
:::
