# 登录

## 打开页面

在浏览器里输入管理员给你的网址，例如 `http://192.168.1.100`。建议把这个地址加入收藏夹。

## 输入账号

登录需要两项：

| 项目 | 说明 |
| --- | --- |
| **工号** | 你的工号，由管理员创建时设定，登录后不能修改 |
| **密码** | 初始密码由管理员告知，建议首次登录后立即修改 |

姓名只用于在界面上显示，**不用来登录**。

填好后点击「登录」。

## 登录后的界面

登录成功后进入**我的文件**页面，左侧是人员目录，右侧是文件列表。

顶部右侧显示你的姓名和工号，点击可以：

- **个人设置** —— 查看自己的信息、修改密码
- **退出登录** —— 退出当前账号

左侧菜单包含：

| 菜单 | 说明 |
| --- | --- |
| 我的文件 | 只看自己上传的文件（这里才能上传、修改和删除） |
| 分享管理 | 查看和管理分享链接 |
| 全部文件（可展开） | 展开后点某个人的名字，浏览他的文件（只能浏览和下载，不能改） |
| 管理（管理员可见） | 工作台、用户、文件与回收站、系统管理 |

## 换成自己的密码

点击右上角姓名 → **个人设置** → **修改密码**：

1. 输入当前密码
2. 输入新密码（至少 6 位）
3. 再输入一次确认
4. 点击「保存并重新登录」

修改成功后**所有已登录的设备都会退出**，需要用新密码重新登录。这是为了防止旧密码泄露后被继续使用。

## 登录不上怎么办

**提示「工号或密码错误」**
检查工号有没有输错（前后不要有空格）、密码大小写是否正确。连续输错多次会暂时被限制，等几分钟再试。

**提示「账号已被停用」**
你的账号被管理员停用了，请联系管理员。

**提示「无法在此网络下使用，请更换网络再试！」**
这说明请求没有到达服务器，通常是**不在公司网络**。连接公司网络或 VPN 后再试。详见[常见问题](../guide/faq)。

**什么都没有发生**
确认网址是否正确、服务器是否在运行。可以联系管理员。
