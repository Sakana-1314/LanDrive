# 浏览与下载

## 按人查看文件

左侧菜单的**全部文件**是一个可以展开的分组：

- 点它只做一件事：**展开或收起**名下的用户列表（它本身不跳转）。
- 展开后列出每个人，**点某个人的名字**就只看他的文件，不必先进列表再筛选。
- 名字右侧的**⋯**可以把这个人的目录**置顶**，方便常用的人排在前面。再点一次取消置顶。

::: tip 置顶是记在自己账号上的
你置顶了谁，只影响你自己看到的顺序；别人看到的还是他自己排的。

置顶记录存在服务端，换电脑、换浏览器登录后依然生效。
:::

右侧列表显示文件名、大小、上传时间和到期时间；从某个人的名字进来时，列表上方会显示当前在看谁。

**文件夹和文件是同一个列表**（和 Windows 资源管理器一样），文件夹排在文件前面：
文件夹行的「大小」列显示的是它里面有多少项，点这一行就进入该目录。

## 搜索文件

在列表上方的搜索框里输入关键词，可以按**文件名**、**上传者姓名**或**工号**搜索；
文件夹按名字单独匹配，所以搜一个目录名也能在结果里看到并进入它。

搜索会立即生效；点「刷新」可以重新加载列表。

## 排序

点击列表表头可以按**文件名**、**大小**、**上传时间**、**到期时间**排序，再点一次切换升序/降序。

## 我的文件

**我的文件**页面只显示你自己上传的文件，并且**上传入口就在这里**——把文件拖到页面任意位置松手即可，也可以点右上方的**上传文件**按钮，不需要再切换到别的页面。

只有在这里（以及管理员）才能修改或删除文件，操作列会出现「重命名」和「删除」按钮。

## 下载文件

在文件行的操作列点击**下载**，文件会保存到浏览器的默认下载目录。

::: tip 文件名是中文也没问题
下载下来的文件名会保持原始名称，包括中文、空格与特殊字符。
:::

## 在线预览

点击**文件名**或操作列的**预览**，会在新标签页打开预览页面，不必先下载。

支持的文件类型见 [在线预览](./preview)。

## 重命名文件

在**我的文件**里点击**重命名**，输入新名称后保存。

::: warning 扩展名不能改
为了保护文件类型策略，**扩展名固定不变**。例如把 `报表.xlsx` 改成 `季度报表`，实际会保存为 `季度报表.xlsx`。
:::

## 删除文件

点击**删除**并确认后，文件会进入**回收站**。

::: warning 删除后自己就看不到了
文件进入回收站后，**包括你本人在内的所有普通用户都无法再看到或下载它**，只有管理员能看到并恢复。

如果需要恢复，请联系管理员，在保留期内（默认 7 天）可以找回。
:::

## 关于到期时间

每个文件都有到期时间，默认是上传后 15 天。列表里「到期」列的标签会显示剩余天数，临近到期时会变成红色提示。

到期后文件自动进入回收站。如果需要长期保存重要文件，可以把它**设为永久**（见下一节），或联系管理员调整保留天数。

## 设为永久保存

重要文件不想被自动清理时，可以在文件行点**设为永久**。设成永久后，这个文件不会随保留期自动清理，只能手动删除。

点击后会弹出**二次确认**，框里会告诉你永久空间一共多少、已经用了多少、这次设完还剩多少 —— 永久空间是整个系统**所有人共享**的，总共 **100 GB**（由管理员配置），所以请按需使用。

::: tip 设错了可以改回来
已设永久的文件，操作列会显示**改回有期限**。点它会按当前的保留天数**重新计算**到期时间（不是恢复成原来的到期时间）。
:::

::: warning 永久空间用完了怎么办
空间不足时无法再设永久，页面会提示还差多少。可以先把一些不再需要的永久文件**删除**（进回收站后就不再占用永久空间），或者联系管理员调大配额。
:::

## 把整个文件夹设为永久

文件夹那一行的操作列有**有效期**按钮，点它可以把**这个文件夹里的全部文件（含所有子文件夹）**一次设为永久，不用一个个点。

弹出的确认框同样会说明范围和永久空间情况，并给出两个选择：

- **设为永久** —— 整个文件夹里的文件都不再自动清理；
- **改回有期限** —— 把它们都改回按保留天数到期。

::: tip 目录本身没有有效期
有效期是**文件**的属性，文件夹只是一次批量操作的范围。所以设完会告诉你「影响了多少个文件」。
:::
