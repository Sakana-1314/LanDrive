# 浏览与下载

## 全部文件

进入**全部文件**页面后，左侧是**人员目录**，列出每个人以及各自的文件数量与占用大小。

- 点击**全部用户**可以看到所有人的文件。
- 点击某个人的名字，只看这个人的文件。
- 右侧列表显示文件名、上传者、大小、上传时间和到期时间。

## 搜索文件

在列表上方的搜索框里输入关键词，可以按**文件名**、**上传者姓名**或**工号**搜索。

搜索会立即生效；点「刷新」可以重新加载列表。

## 排序

点击列表表头可以按**文件名**、**大小**、**上传时间**、**到期时间**排序，再点一次切换升序/降序。

## 我的文件

**我的文件**页面只显示你自己上传的文件。

这里和「全部文件」的区别是：**只有在这里（以及管理员）才能修改或删除文件**，操作列会出现「重命名」和「删除」按钮。

## 下载文件

在文件行的操作列点击**下载**，文件会保存到浏览器的默认下载目录。

::: tip 文件名是中文也没问题
下载下来的文件名会保持原始名称，包括中文、空格与特殊字符。
:::

## 在线预览

点击**文件名**或操作列的**预览**，会在新标签页打开预览页面，不必先下载。

支持的文件类型见 [在线预览](./preview)。

## 重命名文件

在**我的文件**（或「全部文件」中自己的文件）里点击**重命名**，输入新名称后保存。

::: warning 扩展名不能改
为了保护文件类型策略，**扩展名固定不变**。例如把 `报表.xlsx` 改成 `季度报表`，实际会保存为 `季度报表.xlsx`。
:::

## 删除文件

点击**删除**并确认后，文件会进入**回收站**。

::: warning 删除后自己就看不到了
文件进入回收站后，**包括你本人在内的所有普通用户都无法再看到或下载它**，只有管理员能看到并恢复。

如果需要恢复，请联系管理员，在保留期内（默认 7 天）可以找回。
:::

## 关于到期时间

每个文件都有到期时间，默认是上传后 15 天。列表里的标签会显示剩余天数，临近到期时会变成红色提示。

到期后文件自动进入回收站。如果需要长期保存重要文件，请在到期前重新上传，或联系管理员调整保留天数。
