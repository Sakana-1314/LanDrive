# 分享文件与文件夹

想把一个文件发给不在内网的同事、客户？用**分享链接**就行，对方不用登录、不用装任何东西，
在浏览器里打开链接就能下载。

## 怎么分享

在**我的文件**里找到要分享的文件，点右边的**分享**按钮，然后选一个有效期：

| 有效期 | 什么时候用 |
| --- | --- |
| **永久**（默认） | 长期给对方用的资料 |
| 1 天 / 3 天 / 7 天 / 30 天 | 临时给对方看一眼，到期自动失效 |

点「创建链接」后，链接会**自动复制到剪贴板**，直接粘贴到聊天工具里发给对方即可。

::: warning 只能分享自己的文件
分享按钮只出现在你自己上传的文件上。别人上传的文件你能浏览、能下载，
但不能替他生成分享链接。
:::

## 文件夹也能分享

进入某个文件夹后，文件夹卡片右侧也有**分享**按钮。对方打开链接可以看到这个文件夹里
有哪些文件，点一下就能把**整个文件夹打包成 zip** 下载走。

## 对方看到什么

打开链接的人不需要登录，会直接看到：

- 文件名和大小，以及**是谁分享的**；
- 图片、PDF、音视频可以直接在页面上看；
- 其他类型（Word、Excel、压缩包等）点按钮下载；
- 有效期状态（比如「剩 3 天」或「永久有效」）。

## 链接为什么会打不开

失效时页面会**明确告诉你原因**，三种情况不是一回事：

| 页面提示 | 意思 | 怎么办 |
| --- | --- | --- |
| **该分享链接已过期** | 有效期到了 | 找分享的人重新生成一个链接 |
| **分享的文件已被删除** | 内容已经不在服务器上了 | 找分享的人确认 |
| **分享链接无效或已被撤销** | 链接不完整，或者分享的人把链接撤销了 | 检查链接是否复制完整 |

## 改名字、挪位置都不影响链接

分享链接指向的是**这个文件本身**，不是它当时所在的位置。所以：

- 你把文件**改个名字**，对方的链接照样能打开，显示的是新名字；
- 你把文件**移到别的文件夹**，链接也照样能用。

反过来，**你把文件删掉**（或删掉它所在的文件夹），对方的链接就会提示
「分享的文件已被删除」—— 这时文件在回收站里，管理员还能恢复；
一旦管理员恢复，**同一个链接会自动重新生效**，不用重新发给对方。

## 管理自己发出的链接

左侧菜单的**分享管理**里能看到所有分享链接：

- 默认显示**所有人创建的**分享（能看到是谁分享的、还剩多少天、被打开过几次），
  这样同一个文件不用重复问别人要链接；
- 点「只看我的」可以筛出自己创建的那些；
- 每个链接都能点**复制**重新拿回地址；
- 不需要了可以点**撤销**，撤销后链接**立刻失效**，已经发出去的也打不开了。

::: tip 永久链接也会留在列表里
永久分享不会自己消失。定期到「分享管理」里清一清已经不用的链接，是个好习惯。
:::
