# 个人设置

点击右上角的姓名 → **个人设置**。

## 查看账号信息

页面顶部显示你的账号信息：

| 项目 | 说明 |
| --- | --- |
| 姓名 | 显示名称，可以重名 |
| 工号 | 登录用，由管理员设定，不可修改 |
| 角色 | 普通用户 / 管理员 |
| 账号状态 | 正常 / 已停用 |
| 我的目录 | 你的文件存放位置 |
| 我的用量 | 你上传了多少个文件、占多少空间 |
| 最后登录 | 上次登录的时间 |
| 创建时间 | 账号创建时间 |

## 修改密码

在「修改密码」区域：

1. 输入**当前密码**
2. 输入**新密码**（至少 6 位）
3. 再输入一次**确认**
4. 点击「保存并重新登录」

修改成功后会跳回登录页，需要用新密码登录。

::: warning 所有设备都会退出
修改密码后，你之前在其它电脑或手机上登录的会话会**立即失效**，需要重新登录。
:::

## 忘记密码

系统不支持自助找回，请联系管理员在**用户管理**里重置。

## 关于我的目录

每位成员都有一个独立目录，你的文件都放在里面。

其他人可以**浏览和下载**你目录里的文件，但**不能修改或删除**。同样，你也不能修改别人的文件。
