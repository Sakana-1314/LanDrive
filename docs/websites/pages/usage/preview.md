# 在线预览

不用下载就能查看文件内容。点击**文件名**或操作列的**预览**，会在新标签页打开预览页面。

## 支持的类型

| 类型 | 格式 | 预览方式 |
| --- | --- | --- |
| 文档 | `.docx` | 渲染为网页，保留排版 |
| 表格 | `.xlsx` | 按工作表显示，可切换标签页 |
| 演示 | `.pptx` | 逐页渲染幻灯片 |
| PDF | `.pdf` | 浏览器内置阅读器 |
| 图片 | `png` `jpg` `jpeg` `gif` `webp` `bmp` `ico` `tiff` | 直接显示 |
| 文本 | `txt` `md` `csv` `log` `json` `xml` `yml` `ini` 及常见代码文件 | 等宽字体显示 |
| 音频 | `mp3` `wav` `m4a` `ogg` `flac` `aac` | 内置播放器 |
| 视频 | `mp4` `webm` `mov` `ogg` | 内置播放器，可拖动进度 |

## 不支持的类型

以下类型**无法在线预览**，点击预览会提示下载后查看：

| 类型 | 原因 | 解决办法 |
| --- | --- | --- |
| `.doc` `.xls` `.ppt` | 旧版二进制格式，浏览器无法解析 | 用 Office 另存为 `.docx` / `.xlsx` / `.pptx` 后重新上传 |
| 压缩包 | 需要解压才能查看 | 下载到本地解压 |
| **超过可预览上限的文件** | 文件太大，在线渲染会卡住浏览器 | **直接下载**到本地打开即可（默认上限 20 MB，由管理员在系统管理里调整） |

体积超限与格式不支持是两回事：超限的文件**照样能下载**，只是不再在线打开。

## 预览页面上的操作

预览页顶部有文件名、类型标签和文件大小，右侧：

- **下载** —— 把文件保存到本地
- **返回** —— 回到之前的页面

## 大文件预览较慢

文档和表格是在浏览器里解析的，文件较大时需要等一会儿，页面会显示「正在加载文件内容…」。

如果表格特别大，为保持流畅，**只渲染前 2000 行 / 100 列**，超出部分会给出提示。需要看完整内容请下载后用 Excel 打开。

超过可预览上限的文件不会走这条路径 —— 直接提示下载，省得白等。

## 文本文件的编码

文本预览会自动识别 **UTF-8** 与 **GBK** 编码，因此 Windows 下保存的中文文本文件通常也能正常显示。

如果文件超过 4 MB，只显示前面的部分内容，避免浏览器卡顿。

## 音视频拖动进度

音频和视频支持拖动进度条。如果发现无法拖动，通常是反向代理没有透传 `Range` 请求头，请联系管理员检查。
