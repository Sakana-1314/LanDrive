# 上传文件

## 上传步骤

1. 在左侧菜单点击**上传文件**
2. 点击虚线框选择文件，或**直接把文件拖进虚线框**
3. 文件出现在下方的**上传队列**中，并自动开始上传
4. 进度条走完、状态变成**已完成**就上传成功了

可以一次选多个文件，它们会依次排队上传。

## 上传队列的含义

每个任务会显示当前状态：

| 状态 | 含义 |
| --- | --- |
| 校验中 | 正在计算文件校验值 |
| 上传中 | 正在传输分片，右侧显示速度和预计剩余时间 |
| 续传中 | 检测到之前没传完，正在接着传 |
| 服务器合并中 | 所有分片传完，服务端正在拼合成完整文件 |
| 已完成 | 上传成功，可以点「预览」查看 |
| 失败 | 上传出错，可以点「重试」 |
| 已取消 | 被手动取消 |

进度条右侧会显示「已传大小 / 总大小」、实时速度和预计剩余时间。

## 大文件与断点续传

大文件会自动切成多个分片并行上传，因此：

- **中途断网**：恢复网络后点「重试」即可，已经传完的分片不会重传。
- **刷新页面或关闭浏览器**：重新打开上传页面，选择**同一个文件**再次上传，系统会识别出未完成的任务并接着传。
- **服务重启**：同上。

::: tip 为什么复传同一个文件能接着传？
系统按「文件名 + 大小 + 最后修改时间」记住未完成的上传任务。只要文件没变，就会复用之前的进度。

所以请**不要修改文件内容后**再传，那样会被当成新文件重新开始。
:::

没有传完的任务会在服务端保留 **24 小时**。超过后临时分片会被自动清理，此时重新上传即可。

## 取消与清理

- **取消**：上传中的任务可以点「取消」，已传的分片会被清理。
- **清除已完成**：队列右上角的按钮可以清掉已结束的任务记录，让列表更清爽（不影响已上传的文件）。

## 上传限制

上传前会先检查，**不符合要求的文件不会被上传，也不会占用服务器空间**：

| 限制 | 默认值 | 说明 |
| --- | --- | --- |
| 单文件最大体积 | 500 MB | 超出的文件会立即提示 |
| 允许的文件类型 | 全部 | 管理员可限制为指定类型 |

页面顶部会显示当前生效的限制。如果提示「该文件类型不被允许上传」，请联系管理员调整。

如果管理员临时关闭了上传功能，页面顶部会显示提示，此时无法上传。

## 上传的文件放在哪里？

上传的文件会进入**你自己的目录**，其他人可以浏览和下载，但只有你能重命名或删除。

上传完成后可以在**我的文件**里找到它。
