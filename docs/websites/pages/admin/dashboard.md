# 统计看板

在左侧菜单进入**管理 → 统计看板**。这里汇总系统的整体情况。

## 顶部指标

| 指标 | 说明 |
| --- | --- |
| 账号总数 | 系统里共有多少个账号 |
| 有效文件数 | 当前可用的文件数量 |
| 占用空间 | 全部有效文件的总大小 |
| 回收站占用 | 已删除但尚未彻底清理的文件数量与大小 |

## 到期提醒

- **未来 7 天内到期** —— 提醒你即将有一批文件被自动清理。如果是重要文件，可以通知上传者重新上传，或到[文件与回收站](./files)里恢复。
- **等待彻底删除** —— 已过保留期、正等待清理任务处理的文件数量。清理任务每隔几分钟执行一次，稍等即可。

## 存储一致性检查

这个功能用于确认**数据库记录与磁盘文件是否一致**，点击「开始扫描」执行。

扫描结果分三类：

| 类型 | 含义 | 处理方式 |
| --- | --- | --- |
| 孤儿文件 | 磁盘上有文件，但数据库里没有记录 | 系统会自动归档到临时目录并保留 7 天后删除 |
| 缺失文件 | 数据库有记录，但磁盘上的文件不见了 | 说明文件被误删或磁盘故障，需要从备份恢复 |
| 非法路径 | 数据库里出现了不合法的路径 | 属于异常数据，建议联系开发者排查 |

::: tip 什么时候用
- 怀疑有文件丢失时
- 手动操作过服务器上的文件或目录后
- 定期巡检（例如每月一次）

全部为 0 表示数据库与磁盘完全对应，这是正常状态。
:::
