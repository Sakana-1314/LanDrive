# 用户管理

在左侧菜单进入**管理 → 用户管理**。这里可以创建账号、调整角色、重置密码、停用或删除账号。

## 创建账号

点击右上角**新建账号**，填写：

| 字段 | 说明 |
| --- | --- |
| 工号 | 登录用，**唯一**，创建后不可修改，不能含空格或斜杠 |
| 姓名 | 用于显示，允许重名 |
| 角色 | 普通用户 / 管理员 |
| 初始密码 | 至少 6 位，建议告知本人后要求其首次登录修改 |

创建成功后，系统会自动为该成员建立独立目录，并把相对路径记录到账号信息里。

## 修改账号

点击某一行的**编辑**，可以修改姓名、角色和启用状态。**工号不可修改**。

把「启用」关闭后，该账号**立即无法登录**，已登录的会话也会失效。

## 重置密码

点击**重置密码**，输入新密码即可。重置后该成员已登录的所有设备会立即失效，需要用新密码重新登录。

## 停用与删除

**停用**（编辑 → 关闭启用）适合临时禁止登录，账号和文件都保留。

**删除**账号时会遇到两种情况：

- 该账号**名下还有文件**：系统会提示文件数量，并拒绝直接删除。
- 需要勾选「同时彻底删除文件」才能删除，此时其**全部文件会永久删除**，不可恢复。

::: danger 删除前请确认
删除账号会连同其目录一起移除。如果只是想收回访问权限，请使用**停用**而不是删除。
:::

## 保护措施

为避免把自己锁在系统外，以下操作会被拒绝：

- 删除自己的账号
- 停用自己的账号
- 把自己降级为普通用户
- 删除或停用系统中**最后一个**可用的管理员

## 列表说明

列表显示每位成员的工号、姓名、角色、状态、文件数、占用空间、目录和最后登录时间，支持按工号或姓名搜索。
