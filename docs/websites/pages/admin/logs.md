# 操作日志

在左侧菜单进入**管理 → 操作日志**。这里记录了系统里发生的所有关键操作。

## 记录了什么

| 操作 | 说明 |
| --- | --- |
| 登录 / 登录失败 | 谁在什么时候登录过，是否失败 |
| 上传 | 谁上传了什么文件、多大 |
| 下载 | 谁下载了什么文件 |
| 重命名 | 谁把文件改成了什么名字 |
| 删除 | 谁删除了文件（进入回收站） |
| 恢复 / 彻底删除 | 管理员的回收站操作 |
| 创建 / 更新 / 删除用户 | 账号变更 |
| 修改 / 重置密码 | 密码变更 |
| 修改配置 | 系统设置的变更内容 |
| 到期标记 / 到期清理 | 自动清理任务执行情况 |

## 筛选日志

- **操作类型** —— 下拉选择只看某类操作，例如只看「删除」。
- **时间范围** —— 今天、近 7 天、近 30 天、近 90 天。
- **关键词** —— 按工号或详情内容搜索。

## 日志保留多久

默认保留 **90 天**，之后由系统自动清理。

如果需要更长的保留时间，可以调整服务端的环境变量 `LANDRIVE_LOG_KEEP_DAYS` 后重启服务。

## 常见用途

**追查文件去向**
如果有人说文件不见了，先按「删除」筛选，看是谁删的；如果是到期清理，日志里会有「到期标记」记录。

**确认是否有异常登录**
按「登录失败」筛选，如果某个工号在短时间内大量失败，可能存在密码猜测。

**审计上传内容**
按「上传」筛选，可以看到谁在什么时候上传了多大的文件。
