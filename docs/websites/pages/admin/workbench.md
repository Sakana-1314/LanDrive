# 工作台

在左侧菜单进入**工作台**。这里汇总系统的整体情况，适合值班时一眼看过去。

## 指标

| 指标 | 说明 |
| --- | --- |
| 账号 | 系统里共有多少个账号 |
| 有效文件 | 当前可用的文件数量 |
| 占用空间 | 全部有效文件的总大小 |
| 回收站 | 已删除但尚未彻底清理的文件数量与大小 |

## 到期提醒

**未来 7 天内到期**时会给出提示：即将有一批文件被自动清理。如果是重要文件，可以通知上传者重新上传，或到[文件与回收站](./files)里恢复。

没有临期文件时会显示「近 7 天没有文件到期」。

## 维护操作

- 存储一致性检查在[系统管理](./settings)里 —— 那是低频的运维动作，和改配置放在一起更顺手。
- 回收站文件的恢复与彻底删除在[文件与回收站](./files)。
