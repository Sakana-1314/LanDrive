# 这是什么

局域网文件助手是一个可以部署在自己服务器上的文件共享网盘，用来在团队或公司内部共享文件。

它解决的核心问题是：**文件需要让所有人看到，但只能由上传者自己改动。**

## 与传统共享文件夹的区别

传统的共享文件夹（如 Windows 共享盘、NAS）通常只有两种做法：要么所有人都能改，要么需要逐个目录分配权限。前者容易误删、误改；后者维护起来很麻烦。

局域网文件助手把「归属」和「可见性」分开：

- **归属**：每个文件都有明确的上传者，只有上传者本人（和管理员）能改名或删除。
- **可见性**：所有登录用户都能浏览、搜索、下载、预览所有人的文件。

所以每个人都有一个属于自己的目录，同时所有人都能看见这些目录里的内容。

## 主要特性

| 特性 | 说明 |
| --- | --- |
| 工号登录 | 用姓名 + 工号 + 密码登录，账号由管理员创建 |
| 独立目录 | 每位成员一个目录，只能修改自己的文件 |
| 全员可读 | 浏览、搜索、下载、预览任意成员的文件 |
| 在线预览 | 常见办公文档与媒体文件无需下载即可查看 |
| 大文件上传 | 分片上传，支持断点续传 |
| 自动清理 | 文件到期自动删除，回收站可恢复 |
| 管理后台 | 用户、容量、类型、日志统一管理 |
