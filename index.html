部署指南
GitHub

一人一目录

每位成员拥有自己的目录，只能修改自己的文件，但可以查看和下载所有人的文件。

在线预览

文档、表格、演示、PDF、图片、文本与音视频都能直接在浏览器里打开，不必先下载。

大文件上传

分片上传与断点续传，网络中断或刷新页面后可以接着传。

自动清理

文件到期自动删除，回收站保留期内可由管理员恢复，磁盘不会越用越乱。

独立部署

部署在自己的服务器上，文件不经过第三方服务。

管理后台

用户管理、容量与类型限制、存储一致性检查。
